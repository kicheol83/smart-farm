# Smart Farm Frontend

Vite, React, TypeScript, MUI, Apollo Client, Socket.io

## 실행

```bash
npm install
cp .env.example .env
npm run dev
```

백엔드(`http://localhost:3000`)가 먼저 실행되어 있어야 합니다.

## 구조

```
src/
├── components/layout/
├── theme/
├── lib/         apollo-client.ts, socket.ts
├── modules/
└── App.tsx
```
